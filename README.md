# Portfolio

Personal portfolio website of Zainab Khan, AI Solutions Engineer.

Live site: see the repository description.

Built with plain HTML, CSS and JavaScript (no build step). Hosted on Vercel.

## Structure

```
index.html        page content
styles.css        design (palette: Ivory, Sand, Plum, Sage, Ocean)
script.js         menu, project filters, scroll effects
images/           photos (profile.jpg goes here)
assets/           résumé PDF (Zainab-Khan-Resume.pdf goes here)
```

## Updating

- Photo: upload `images/profile.jpg` (portrait, about 4:5).
- Résumé: upload `assets/Zainab-Khan-Resume.pdf`. The résumé buttons appear automatically once it exists.
- Text: edit `index.html` and commit. Vercel republishes within a minute or two.
