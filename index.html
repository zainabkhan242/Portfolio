AI & Machine Learning · Hackathon Project

RepoSetup-Bench

A reinforcement-learning benchmark for assessing how well AI coding agents prepare a repository for publication.

  • Python
  • Gymnasium
  • Reinforcement Learning
  • LLM Evaluation
  • pytest
View on GitHub ↗

Context

AI assistants often configure projects with confidence but without accuracy, leaving generated files committed and documentation that describes the wrong stack. RepoSetup-Bench was built to measure the outcome rather than the impression.

Approach

A Gymnasium environment presents an agent with a repository containing common setup issues. The agent is expected to configure .gitignore correctly, untrack generated and sensitive files without deleting them, remove nested .git folders, and write a README grounded in the actual code.

A reward function scores eight weighted checks, while safeguards against reward hacking assign a score of zero to agents that delete files or ignore the repository wholesale.

Outcomes

  • Three task repositories: Django with React, Express with React, and Flask
  • Six scripted agents, including two designed to cheat, both scoring 0.00
  • A well-written but inaccurate README scores 0.04 on average, as the verifier checks content against the code
  • Seventeen automated tests, an HTML report of each agent's trajectory, and support for live LLM agents

A hackathon prototype. Results reflect scripted agents. Live-model evaluation is supported.

Full-Stack · Internship Project, Gorai Technology Solutions

Recruiter Portal

A data-driven application for managing candidates and matching them to open roles.

  • React
  • Node.js
  • Express
  • MongoDB
  • Mongoose
  • Multer
View on GitHub ↗

Context

Candidate details and resumes were held in separate places, which slowed down shortlisting.

Approach

A React interface backed by a Node.js and Express API and a MongoDB database. Recruiters add candidates, upload resumes and select a skill and job title, and the system returns the five closest matches.

Outcomes

  • Candidate matching by skill and job title, using case-insensitive queries
  • Skill and role reference data seeded into and served from MongoDB
  • Server-side resume uploads with Multer
  • Candidate cards that show each profile at a glance
